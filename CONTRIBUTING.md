# Contribuer à ce projet :

Tout d'abord, merci de prendre le temps de contribuer ! Ce projet est axé sur la reproductibilité, et toutes les contributions, suggestions et corrections sont les bienvenues.
Ce document décrit le processus à suivre pour contribuer efficacement à ce projet.

## 🤝 Attentes communautaires et comportementales

En participant à ce projet, vous acceptez de respecter notre Code de Conduite.
Nous nous engageons à offrir un environnement accueillant et inspirant pour tout le monde. Restez respectueux, constructif et bienveillant dans vos échanges, que ce soit dans les Issues ou les Pull Requests.

## 🐛 Signaler un problème (Créer une bonne Issue)

Si vous trouvez un bug ou si vous avez une proposition d'amélioration, veuillez créer une Issue. Pour qu'elle soit la plus utile possible, incluez les éléments suivants :

Un titre clair et descriptif résumant le problème.

Les étapes pour reproduire le bug, étape par étape.

Le comportement attendu par rapport au comportement observé.

Votre environnement (système d'exploitation, version de Python/R/autre, etc.).

## 🛠️ Proposer une modification (Créer une bonne Pull Request)

Nous utilisons le flux de travail classique de GitHub. Voici les étapes pour soumettre votre code :

Forkez le dépôt (créez une copie sur votre propre compte GitHub).

Clonez votre fork localement 

Créez une branche pour votre fonctionnalité ou correction

Faites vos modifications en gardant à l'esprit la reproductibilité du projet.

Commitez vos changements avec des messages clairs et descriptifs 

Poussez votre branche sur votre fork 

Ouvrez une Pull Request depuis votre branche vers la branche main du dépôt original.

Dans la description de votre Pull Request, expliquez clairement ce que vous avez modifié et liez-la à une Issue existante si possible (ex: "Closes #3").

## 📚 Besoin d'aide ? 

Pour mieux comprendre le projet et son contexte de reproductibilité, vous pouvez envoyer un message dans l'onglet community ou directement à lucausz (propriétaire du repo)

Merci encore pour votre aide !
